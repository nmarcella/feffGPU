# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and constructive; criticize ideas and code, not people; harassment and personal attacks are
not accepted in issues, pull requests, discussions or any other space of this project.

To report a problem, contact the maintainers privately through the contact options of the repository owner's GitHub
profile, or use GitHub's "Report content" function on the item concerned. Reports are handled confidentially.
Maintainers may edit or remove contributions that break these rules and may block people who repeat the behavior.
